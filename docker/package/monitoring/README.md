# Monitoring assets

Copied from the pinned Sourcegraph source (`SOURCEGRAPH_COMMIT` in
`../versions.env`) so the image can run the optional observability stack
without a second network build:

- `*_alert_rules.yml` — generated by the monitoring generator:

  ```sh
  cd .package-build/sourcegraph/monitoring
  go run . generate -all.dir /tmp/monitoring
  ```

- `prometheus_targets.yml` — copied verbatim from
  `.package-build/sourcegraph/dev/prometheus/linux/prometheus_targets.yml`
  (the single-container target list; identical to the file shipped in the
  official `sourcegraph/server:5.5.0` image).

Regenerate both when bumping `SOURCEGRAPH_COMMIT`.
